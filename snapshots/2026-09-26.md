## 캐페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

**이번 실행 요약:** Microsoft 원문을 재페치·재확인했으나 31개 도메인 목록에 변화 없음(신규 없음, 폐기 없음). 지정 3건 중 ThreatFox·Beelzebub는 계속 차단. WebSearch에서 "MacSync 신버전"(iCloud 캘린더 매개 전달, Finder 위장 백도어 등) 서술의 1차 출처로 추정되는 Kaspersky Securelist 원문(securelist.com/macsync-new-version/121383/)과 CIS(Center for Internet Security)의 "MacSync Stealer Campaign Impacting U.S. SLTT macOS Users" 게시글을 새로 특정했으나, 둘 다 프록시에 차단되어 원문 확보 실패. helpnetsecurity.com, technadu.com 등 재보도 매체도 동일 서술을 반복할 뿐 신규 기술 세부사항 없음. Trend Micro의 "InstallFix and Claude Code" 원문도 재시도했으나 계속 차단. 가짜 Claude 설치 페이지와 MacSync 신버전 상세 간의 직접적 연결점은 이번 실행에서도 확인되지 않음.

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — "Claude Code install", "Claude Code CLI" 등 검색 시 노출되는 스폰서 링크로 유도
2. 터미널 명령 복사·붙여넣기 유도 — ClickFix 방식으로 터미널에 직접 명령 붙여넣기 유도 (seed)
3. Mach-O 다운로드 · Gatekeeper 우회 — 아키텍처별 Mach-O 다운로드 후 `xattr -rd com.apple.quarantine` 격리속성 제거, `codesign --force --sign -` 애드혹 재서명 (seed)
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/cksyncd` 및 `.cksyncd.v` 배치, `open -g -j -n -a --args`로 은닉 실행 (seed)
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 프로파일로 Chromium 실행해 쿠키·세션 판독, Firefox/Safari 데이터도 수집 (seed)
6. 외부 유출 · 세션 재사용 위험 — `/curl/`, `/dynamic?txd=`, `/gate?buildtxd=` 경로로 HTTP PUT + `--data-binary` 청크 업로드(`upload_id`, `chunk_index`, `total_chunks`), `api-key` 헤더 사용 (verified, Microsoft 2026-08-18)
