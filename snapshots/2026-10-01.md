## 캐페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

**금일 조사 메모:** Microsoft(2026-08-18) 원문 재페치 결과 기존 검증 도메인 31건 및 행동 패턴 동일하되, 이번 재페치 본문에서 curl 플래그(`-k`, `-s`, `--max-time 30`)가 "Notable URI Patterns & HTTP Details" 항목으로 명시적으로 확인되어 2026-09-21에 기록했던 미검증 서술을 **verified로 승격**했다(네트워크/C2 섹션 및 host-iocs.md 반영). ThreatFox·Beelzebub은 이번에도 차단. 신규로 시도한 Rescana("Claude LLM Artifacts Exploited to Distribute Mac Infostealer Malware via ClickFix Attack Chain Targeting macOS Users"), Zscaler("ClaudeFix: Shared Claude Chats Meet ClickFix"), Rapid7(가짜 Claude 설치 페이지/Windows InstallFix), Trend Micro("InstallFix and Claude Code"), SOC Prime 5건 모두 프록시 차단으로 원문 미확보 — 다만 Rescana·Zscaler 제목이 2026-09-20에 기록한 "공유된 Claude 대화 링크 유인 벡터" 서술(당시 단일 출처)을 독립적으로 보강하며, Rescana는 macOS를 명시적으로 특정함(다중 출처 확보, 여전히 미검증). 검색 스니펫 합성 요약에서 MacSync 신버전(iCloud 캘린더 매개)의 배포 URL 후보로 `toria.app`, `warpcast.asia`, `streamyard.appstore.com.mx`, `slack.apple03cloudstore.com` 4건이 추가로 확인되었으나, 가짜 Claude 설치 페이지와의 연결점이 없고 출처가 특정 기사 본문이 아닌 검색엔진 합성 요약이라 매우 낮은 신뢰도의 미검증 후보로만 `unverified-domains.txt`에 참고 등록(차단 금지). "서명된 macOS 앱" 변종(cybersecuritynews.com, 차단)도 재보도 확인되었으나 신규 기술 세부사항은 없음.

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — "Claude Code", "Claude Code install", "Claude Code CLI" 등 검색 시 노출되는 스폰서 링크로 유도 (⚠️ 미검증, 타 벤더 스니펫 기반)
2. 터미널 명령 복사·붙여넣기 유도 — ClickFix 기법으로 피해자가 직접 명령 실행 (T1204.004)
3. Mach-O 다운로드 · Gatekeeper 우회 — `xattr -rd com.apple.quarantine` 후 `codesign --force --sign -`로 애드혹 재서명
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/cksyncd` 등 위장 경로에 배치
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 프로파일로 Chromium 실행, Firefox/Safari 데이터도 수집
6. 외부 유출 · 세션 재사용 위험 — HTTP PUT + `--data-binary` (curl `-k -s --max-time 30`), 청크 업로드(`upload_id`/`chunk_index`/`total_chunks`)로 C2에 전송
