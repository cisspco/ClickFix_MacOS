## 캐페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

**신규 미검증 서술 (이번 실행, 검색 스니펫 기반 — 원문 대부분 차단):**
- ⚠️ (미검증) LaaS(Loader-as-a-Service) 진화 서술 강화 — 2026-02 시작된 세 번째 추적 캠페인이 네이티브 Mach-O 직접 전달을 멀티스테이지 LaaS 모델(쉘 기반 로더, API 키 게이트형 C2, 동적 AppleScript 페이로드, 인메모리 실행)로 대체했다는 서술. 기존 "파일리스/인메모리 실행 변종"(2026-09-17)을 구체화하나 원문 미확인.
- ⚠️ (미검증, 채택 보류) 피해자 규모 통계 "15,600명 이상" — 동일 스니펫이 MSIX/HTA/PowerShell/mshta.exe 등 Windows 전용 세부사항과 함께 기술되어 있어 macOS/MacSync가 아닌 InstallFix Windows측 수치일 가능성.
- ⚠️ (미검증, 채택 보류) Netskope AppleScript 계열 캠페인(ClickFix→AMOS, 2026-07-28부터 추적, 합법 WordPress 사이트 경유, 가짜 "Bot Protection" 화면) 재확인 — 가짜 Claude 설치 페이지·MacSync와의 연결점 미확인, 혼동 주의용으로만 기록.
- Microsoft 2026-05-06 별도 리포트("fake macOS utilities lures") 확인 — 가짜 macOS 유틸리티 위장이며 가짜 Claude 설치 페이지 미언급, 본 캠페인과 무관 — 혼동 방지용 기록.

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — "Claude Code install", "Claude Code CLI" 등 검색 시 노출되는 스폰서 링크로 유도, Squarespace/Google Sites 외 Cloudflare Pages·Tencent EdgeOne 등 정상 플랫폼 악용 서술도 존재(미검증). 공유된 Claude 대화 링크를 유인으로 쓴다는 서술도 있음(미검증).
2. 터미널 명령 복사·붙여넣기 유도 — ClickFix 방식으로 터미널에 직접 명령 붙여넣기 유도 (seed)
3. Mach-O 다운로드 · Gatekeeper 우회 — 아키텍처별(유니버설 바이너리 추정) Mach-O 다운로드 후 `xattr -rd com.apple.quarantine` 격리속성 제거, `codesign --force --sign -` 애드혹 재서명 (seed)
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/cksyncd` 및 `.cksyncd.v` 배치, `open -g -j -n -a --args`로 은닉 실행 (seed)
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 프로파일로 Chromium 실행해 쿠키·세션 판독, Firefox/Safari 데이터도 수집 (seed)
6. 외부 유출 · 세션 재사용 위험 — `/curl/`, `/dynamic?txd=`, `/gate?buildtxd=` 경로로 HTTP PUT + `--data-binary` 청크 업로드(`upload_id`, `chunk_index`, `total_chunks`), `api-key` 헤더 사용 (verified, Microsoft 2026-08-18)
