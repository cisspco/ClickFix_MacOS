## 캠페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — 사용자가 "claude desktop", "claude code" 등을 검색하면 노출되는 사기성 광고를 통해 가짜 설치 페이지로 유입
2. 터미널 명령 복사·붙여넣기 유도 — 페이지가 "설치 안내"를 가장해 터미널 명령을 복사·붙여넣도록 유도 (ClickFix, T1204.004)
3. Mach-O 다운로드 · Gatekeeper 우회 — 아키텍처에 맞는 Mach-O 바이너리 다운로드 후 `xattr -rd com.apple.quarantine`으로 격리 속성 제거, `codesign --force --sign -`로 애드혹 재서명하여 실행
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/` 하위에 `cksyncd`, `.cksyncd.v` 등으로 위장 배치
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 옵션으로 Chromium을 숨김 실행(`open -g -j -n -a --args`)하여 쿠키·프로파일 판독, Safari·Firefox 데이터도 수집. 스테이징 경로 `/tmp/sync*`, `/tmp/osalogging.zip`
6. 외부 유출 · 세션 재사용 위험 — `/curl/`, `/dynamic?txd=`, `/gate?buildtxd=` 등 URI 패턴과 HTTP PUT + `--data-binary`로 청크 단위(`upload_id`, `chunk_index`, `total_chunks`) 업로드. 탈취된 세션 쿠키로 MFA 우회 및 기존 로그인 재사용 가능
