## 캐페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

🔥⚠️ (미검증, 원문 미확인 — 검색 스니펫 기반) Kaspersky가 2026-09-17경 MacSync의 새 변종을 발견했다고 보도됨. 더 복잡한 감염 체인을 사용하며 인포스틸러와 백도어를 함께 전달, 자격증명·각종 사용자 데이터·암호화폐 자산을 노린다고 함. 이전 실행에서 기록된 Huntress의 "RAT 컴포넌트" 미검증 서술과 일치하는 방향(단순 브라우저 스틸러 → 백도어/RAT 겸용으로 진화). 출처(Kaspersky 원문 또는 이를 인용한 lifestyleandtech.co.za, brandiconimage.com)는 이번 실행에서 모두 접근 실패.

⚠️ (미검증) Trend Micro("InstallFix and Claude Code")가 동일 캠페인이 Windows와 macOS에 플랫폼별로 다른 악성코드를 배포한다고 명시적으로 언급(검색 스니펫, 원문 차단) — 이전 실행의 "InstallFix 연관 가능성" 미검증 서술을 강화. Windows측 IOC는 여전히 본 저장소 범위 밖.

⚠️ (미검증) 별도 검색 스니펫에서 Google Ads 기반 ClickFix 캠페인이 DMG를 통해 Mach-O를 전달하며 페이로드로 "Macsync, Shub Stealer, AMOS" 등을 언급(Unit42 관련 GitHub 리포지토리, 원문 미확인) — 직접 다운로드형 Mach-O(seed) 외에 DMG 매개 배포 변형이 존재할 가능성. 원문 미확인으로 host-iocs.md에 미검증으로만 기록.

⚠️ (미검증) Malwarebytes("Fake Claude search results lure Mac users into ClickFix attack", 2026-05)가 동일 macOS/Claude 사칭 ClickFix 캠페인을 독립적으로 다룬 것으로 보이나 원문 차단으로 세부 IOC 미확인 — 교차 확인 벤더 목록에 추가.

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — "Claude Code install", "Claude Code CLI" 등 검색 시 노출되는 스폰서 링크로 유도 (seed + 다수 벤더 교차 확인, 미검증 세부)
2. 터미널 명령 복사·붙여넣기 유도 — ClickFix 방식으로 터미널에 직접 명령 붙여넣기 유도 (seed)
3. Mach-O 다운로드 · Gatekeeper 우회 — 아키텍처별 Mach-O 다운로드 후 `xattr -rd com.apple.quarantine` 격리속성 제거, `codesign --force --sign -` 애드혹 재서명 (seed)
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/cksyncd` 및 `.cksyncd.v` 배치, `open -g -j -n -a --args`로 은닉 실행 (seed)
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 프로파일로 Chromium 실행해 쿠키·세션 판독, Firefox/Safari 데이터도 수집 (seed)
6. 외부 유출 · 세션 재사용 위험 — `/curl/`, `/dynamic?txd=`, `/gate?buildtxd=` 경로로 HTTP PUT + `--data-binary` 청크 업로드(`upload_id`, `chunk_index`, `total_chunks`), `api-key` 헤더 사용 (verified, Microsoft 2026-08-18)
