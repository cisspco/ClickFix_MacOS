## 캐페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

**신규 미검증 서술 (이번 실행, 검색 스니펫 기반 — 원문 모두 차단):**
- ⚠️ (미검증) 일부 보도(Google Sites + iframe 방식)에 따르면 피해자가 먼저 Google Sites 페이지에 도달하고, 공격자 인프라에서 iframe으로 끌어온 콘텐츠가 표시되며, Squarespace 문서 페이지 복제(2026-09-19 기록)와 함께 별개/추가 호스팅 경로로 사용된 것으로 보임 (Bitdefender 관련 서술, 원문 차단).
- ⚠️ (미검증) 일부 보도(cybersecuritynews.com, 원문 차단)에 따르면 검색광고 외에 "공유된 Claude 대화(chat) 링크"도 유인 벡터로 사용되었다는 서술 있음 — 기존 seed의 "검색광고" 벡터에 추가되는 신규 유인 경로 가능성.
- ⚠️ (미검증) 일부 보도에서 최종 Mach-O 바이너리가 "universal binary"(Intel + Apple Silicon 겸용)라는 서술 확인 — seed의 "아키텍처에 맞는 Mach-O" 표현을 구체화.
- **주의(채택 보류):** 일부 검색 결과가 "Amatera Stealer"라는 별도 멀웨어명을 이 캠페인과 연결지어 언급하나, Amatera Stealer는 통상 Windows 대상 스틸러로 알려진 별개 패밀리이며 원문 확인 불가. 2026-09-19의 Unit42/AMOS 오탐 사례와 유사한 혼동 가능성이 있어 본 캠페인 IOC로 채택하지 않음(host-iocs.md에 주의사항으로만 기록).

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — "Claude Code install", "Claude Code CLI" 등 검색 시 노출되는 스폰서 링크로 유도, 일부는 Squarespace 서브도메인에 정식 문서 페이지를 복제해 호스팅하거나 Google Sites + iframe 경로를 사용 (seed + 다수 벤더 교차 확인, 호스팅 세부는 미검증). 공유된 Claude 대화 링크를 유인으로 쓴다는 서술도 있음(미검증).
2. 터미널 명령 복사·붙여넣기 유도 — ClickFix 방식으로 터미널에 직접 명령 붙여넣기 유도 (seed)
3. Mach-O 다운로드 · Gatekeeper 우회 — 아키텍처별(유니버설 바이너리 추정) Mach-O 다운로드 후 `xattr -rd com.apple.quarantine` 격리속성 제거, `codesign --force --sign -` 애드혹 재서명 (seed)
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/cksyncd` 및 `.cksyncd.v` 배치, `open -g -j -n -a --args`로 은닉 실행 (seed)
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 프로파일로 Chromium 실행해 쿠키·세션 판독, Firefox/Safari 데이터도 수집 (seed)
6. 외부 유출 · 세션 재사용 위험 — `/curl/`, `/dynamic?txd=`, `/gate?buildtxd=` 경로로 HTTP PUT + `--data-binary` 청크 업로드(`upload_id`, `chunk_index`, `total_chunks`), `api-key` 헤더 사용 (verified, Microsoft 2026-08-18)
