## 캠페인 개요
가짜 Claude Desktop/Claude Code 설치 페이지(검색광고)를 통한 ClickFix 기법으로 사용자가 터미널에 명령을 직접 붙여넣게 유도하고, 아키텍처에 맞는 악성 Mach-O를 다운로드·실행. MacSync 모듈이 Chromium계·Firefox·Safari 쿠키·프로파일을 수집해 외부로 유출. 탈취된 세션 쿠키로 기존 로그인 재사용 가능.

**금일 조사 메모:** Microsoft(2026-08-18) 원문을 재페치해 기존 검증 도메인 31건 및 행동 패턴이 동일함을 재확인했다. 이번 재페치에서 원문이 해시·IP·ASN·지속성 메커니즘·가짜 Claude Desktop 배포 전용 도메인은 "제공하지 않는다"고 명시하는 부분을 새로 확인 — 즉 Microsoft 출처는 MacSync의 C2 행위 피벗만 다루며, 가짜 Claude 설치 페이지와의 연결 고리 자체는 이번에도 차단된 Rescana/Zscaler/SOC Prime/Rapid7 등 별도 출처에 의존한다는 점이 재확인됐다(기존 verified 항목 범위 명확화, 신규 IOC는 아님). ThreatFox·Beelzebub은 이번에도 차단. 신규로 시도한 Rapid7, Malwarebytes("Fake Claude search results lure Mac users into ClickFix attack"), Zscaler, Securelist(Kaspersky MacSync 신버전 원문 추정), RST Cloud("MacSync Stealer: C2 Infrastructure Rotation")도 모두 프록시 차단으로 원문 미확보. 다만 WebSearch 합성 요약(MS-ISAC/RST Cloud 계열로 추정, 원문 1차 출처 미특정)에서 도메인 `jacksonvillemma[.]com`과 URL `http://jacksonvillemma[.]com/curl/<sha256>`, Stage 2 zsh 로더로 추정되는 MD5/SHA-1/SHA-256 해시 세트를 신규로 확인 — URL 경로의 `/curl/` 패턴이 Microsoft 검증 URI 패턴과 일치해 동일 MacSync 인프라 계열일 가능성이 있으나, 검색 스니펫 합성 요약만으로 확인되어 미검증으로만 등록했다. 또한 SANS ISC의 별개 명칭 "Macfinger" ClickFix 캠페인과, popularai.org의 "스캠 체인 후반부에 정식 claude.ai 링크 재사용" 서술을 혼동 방지용 맥락 정보로 기록했다(둘 다 원문 미페치, IOC 미채택).

## 공격 체인
1. 가짜 설치 페이지 유도 (검색광고) — "Claude Code", "Claude Code install", "Claude Code CLI" 등 검색 시 노출되는 스폰서 링크로 유도 (⚠️ 미검증, 타 벤더 스니펫 기반)
2. 터미널 명령 복사·붙여넣기 유도 — ClickFix 기법으로 피해자가 직접 명령 실행 (T1204.004)
3. Mach-O 다운로드 · Gatekeeper 우회 — `xattr -rd com.apple.quarantine` 후 `codesign --force --sign -`로 애드혹 재서명
4. 지속성 (cksyncd) — `~/Library/Application Support/.com.apple.airport/cksyncd` 등 위장 경로에 배치
5. 브라우저 정보 탈취 (MacSync) — `--user-data-dir=<...cksync...>` 프로파일로 Chromium 실행, Firefox/Safari 데이터도 수집
6. 외부 유출 · 세션 재사용 위험 — HTTP PUT + `--data-binary` (curl `-k -s --max-time 30`), 청크 업로드(`upload_id`/`chunk_index`/`total_chunks`)로 C2에 전송
